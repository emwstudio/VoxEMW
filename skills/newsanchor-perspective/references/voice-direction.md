# TTS 克隆音色指南：突发快讯主播

> 用途：为「BBC 插播快讯式中文突发新闻主播」人设挑选/制作 TTS 克隆参考音色（ref.wav + ref.txt）。
> 依据：见同目录 `research/01-expression-dna.md`（语速、节奏数据）与 `research/03-anti-patterns.md`（腔调红线）。

---

## 一、音色画像

| 维度 | 要求 | 说明 |
|------|------|------|
| 性别 | 男声优先，女声亦可 | 参考系：央视《新闻联播》男主播、BBC 中文广播男声。女声选「新闻腔」而非「甜美腔」 |
| 年龄感 | 35–50 岁 | 成熟、稳定、有「坐镇感」；不要青年感（压不住突发）、不要老年感（语速跟不上） |
| 音高 | 男声中低音区（约 100–150 Hz 基频） | 偏低但不压嗓子——刻意压嗓是反模式（「为显得权威而表演腔调」）；女声取自然音区偏下 |
| 音色质地 | 圆润、饱满、共鸣足（「枣核型」吐字） | 韵母饱满、字音响亮，吐字归音完整；沙哑、气声、娃娃音一票否决 |
| 语速 | 260–300 字/分钟 | 快讯基准语速。注意：「快」靠信息密度和咬字利落，不靠发音含混；字清是绝对前提 |
| 节奏 | 句内紧凑、句间干净 | 停顿点即信息切分点；句子内部不停顿；重音落在数字、地名、动词、时间词上 |
| 情绪基调 | 中性偏肃，冷静克制 | 「声取其中」——可以有庄重感，不能有心跳声。句尾降调，无上扬、无拖腔、无叹气的空间 |

## 二、可参考的真实主播与片段类型

**直接参考（按匹配度排序）：**

1. **央视《新闻联播》男主播的日常口播**（康辉、刚强、潘涛任一场次）——中文新闻播音的基准音色：300 字/分、字字清晰、零情绪波动。
2. **央视突发插播/滚动新闻片段**（CCTV-13 新闻频道突发报道开场 30 秒）——目标场景本身，注意听「现在插播」「本台刚刚收到的消息」的信号感。
3. **BBC 中文/BBC World Service 的 breaking news 插播**——「克制即权威」的标杆，重点学它的「坏消息也不变调」。
4. **彭博/路透电视快讯的中文转播或同声传译片段**——财经快讯的高密度节奏参考。

**反面参照（选音色时排除）：**

- 纪录片旁白腔（太慢、太有感情）
- 电台深夜节目腔（气声、耳语感）
- 短视频「注意看」式自媒体配音（促销重音、悬念腔）
- 有声书演播（角色化、戏剧化）

**选段实操建议**：截 ref.wav 时选**纯口播段**——无背景音乐、无现场同期声、无连线杂音；主播连续播报 10–30 秒、中途无长停顿的一段为最佳。突发插播开场段（含「现在插播一条快讯」类信号句）优于常态新闻段。

## 三、示范播报逐字稿（ref.txt 配套文本）

约 110 字，按 260–280 字/分钟播报，时长约 24–27 秒。事件为虚构（「临江市」），可放心录制/截取。录制要点：开场信号句略提紧迫感但不升调；数字落重音；「本台将持续关注」降调收口，干脆结束。

```
现在插播一条本台刚刚收到的消息。据临江市应急管理局通报，今天下午两点二十分，该市港区一化工厂发生爆炸，已确认至少三人死亡、十七人受伤，伤员已全部送医。消防救援仍在现场处置，事故原因正在调查。以上数字以官方通报为准，本台将持续关注。
```

**自检清单（录完/截完对照）：**

- [ ] 全文无一次情绪上扬、无一次感叹语气
- [ ] 「三人死亡、十七人受伤」数字清晰、有重音、不含糊
- [ ] 句间停顿干净利落，句内无碎停顿
- [ ] 最后一句说完即收，无尾音、无渐弱淡出
- [ ] 整体听感：「出事了，但他很稳」——而不是「出大事了！」
